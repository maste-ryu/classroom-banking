# 功能需求

本文件記錄系統應提供的功能。已確認規則依 SPEC.md 與本文件記載；未確認部分標示待確認。

## 班級與成員
- 建立及管理班級：待確認
- 新增、編輯、停用或移除成員：教師操作
- 成員識別方式與重複資料處理：待確認

## 薪資與帳務
- 設定薪資或定期收入：教師設定，計算細節依記點行為規則
- 記錄收入、支出、獎勵與扣款：教師操作；每日記薪每次確認都新增交易，不設重複入帳防止機制
- 查詢個人及全班帳戶總餘額、異動明細
- 更正或撤銷錯誤紀錄：待確認

## 帳戶與報表
- 不進行月結，不因月份切換而重設或轉移餘額
- 帳戶總餘額由所有有效交易計算
- 報表及資料匯出格式：待確認

## 權限與稽核
- 教師可管理班級、成員、行為、交易、商品及兌換
- 學生只有查看權限；不能修改資料或自行執行兌換。商店兌換由教師代為操作
- 交易與更正紀錄須在資料庫保存操作者及時間
- 教師以 Supabase Auth 電子郵件/密碼登入；教師帳戶由專案管理者建立

## 技術與部署

- 靜態前端部署於 GitHub Pages，GitHub Actions 負責生成前端連線設定並部署。
- Supabase Auth 提供教師登入；Postgres 保存班級、學生、商店與交易流水。
- Supabase RLS 依教師/學生角色及班級範圍限制資料存取。
- Supabase Storage 使用私有 bucket 保存學生照片。
- 網頁只可使用 Supabase publishable key；不得使用 secret/service-role key。
