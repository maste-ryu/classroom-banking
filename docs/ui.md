# UI/UX 規格

## 使用平台

網頁應用程式，優先支援教師桌面操作，並具備手機基本響應式版面。靜態網站部署於 GitHub Pages；登入使用 Supabase Auth。

## 預計頁面

- **班級總覽**：呈現班級與整體帳務摘要；內容待確認。
- **成員列表／個人帳戶**：查詢成員與個人餘額、異動；操作權限待確認。
- **新增異動**：輸入薪資、記點、扣薪或其他交易；欄位待確認。
- **皮克敏展示**：展示可取得的皮克敏種類及每累積 500 分由教師手動新增一隻的規則。
- **皮克敏種類管理**：教師可在展示頁新增、編輯或刪除展示種類與圖片。
- **新增皮克敏**：教師在管理區獨立選擇學生與皮克敏種類，直接新增收藏，不扣款。
- **設定**：管理班級、成員、薪資規則與權限；範圍待確認。

## 共通設計要求

- 金額、點數、日期及交易方向應清楚標示。
- 重要帳務操作應提供確認與結果回饋。
- 表單應呈現必要欄位、輸入限制及錯誤訊息。
- 無資料、載入中及操作失敗狀態需有明確提示。

以上介面項目為規劃草案，需依確認後的需求調整。

## 已確認權限與流程

- 學生介面為唯讀，只能查看個人資料、餘額、帳本與皮克敏收藏。
- 皮克敏在學生累積每 500 分後由教師手動新增，不使用兌換流程。
- 每日記薪不需重複入帳提示或阻擋；教師每次確認入帳都會新增一組交易。
- 不提供月結操作；餘額始終為帳戶總餘額。
- 餘額以清楚的數字為準，旁邊顯示金幣堆疊圖作為視覺化提示；堆疊高度以有限級距呈現，避免餘額大時圖像無限制增高。
- 皮克敏新增不會產生帳務交易；保留教師與新增時間紀錄。

## 初版已實作頁面

- 教師登入
- 帳戶總覽、金幣堆疊與學生帳戶卡
- 新增薪資/扣款/帳務更正
- 交易流水與文字/類型篩選
- 新增學生帳戶
- 皮克敏展示與教師手動新增

學生登入、學生照片上傳和行為範本矩陣仍待完成。
